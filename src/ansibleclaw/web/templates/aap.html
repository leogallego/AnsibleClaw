Setup Instructions

Set these environment variables before starting AnsibleClaw to enable AAP mode:

export AAP_CONTROLLER_URL="https://aap.example.com"
export AAP_CONTROLLER_TOKEN="your-oauth2-token"
export AAP_VERIFY_SSL="true"
export AAP_DEFAULT_INVENTORY="Production"
export AAP_DEFAULT_CREDENTIAL="Machine SSH Key"

Generate a token in the AAP/AWX web UI under Users → your user → Tokens.

Once configured, all generated skills will include a Production Execution (AAP) section with API examples and an aap_run.py helper script.
